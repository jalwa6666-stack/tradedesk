# TradeDesk demo starter

A responsive Quotex-inspired **demo-only** trading dashboard prototype.

## Run locally
1. Install Node.js (18+).
2. In this folder run: `npm install`
3. Run: `npm run dev`
4. Open the local URL printed by Vite.

## Included
- Responsive desktop/mobile dashboard
- Simulated price line (not live market data)
- Demo balance and randomly simulated UP/DOWN outcomes
- Recent demo trade history

## Not included / intentionally disabled
- Real-money trading, deposits, withdrawals, broker connectivity, identity verification, or payment processing.
- The demo result generator is for UI testing only and is not a prediction or trading engine.

## Next production steps
Before any real-money feature: obtain jurisdiction-specific legal advice and required licences/authorisations; choose an authorised broker/data provider; complete KYC/AML, privacy, security, responsible-trading, audit, and payment-provider reviews. Keep real-money flows disabled until those approvals are verified.
